Predator Control includes Microsoft .NET 10 and the Microsoft WebView2 SDK integration.
Jelli uses the Microsoft Edge WebView2 Runtime already installed for Windows. Predator Control does not bundle or install a browser runtime.
The native WebView2 loader is stored separately in the protected PredatorControlData folder.
