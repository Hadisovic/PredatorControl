# Predator Control 1.2.0 · Jelli

Built from the `jelli` branch. This release brings the Jelli desktop creature and React control surface to the existing Predator Control hardware backend.

## What's new

- A draggable desktop companion with two configurable, unboxed readouts that float independently.
- Click for a summary, double-click for the dashboard, and right-click for quick controls.
- System, Lighting, Games and Settings tabs, plus expandable and attached-flyout presentations.
- Refined deep-sea styling, panel and tab transitions, hover/press feedback and reduced-motion support.
- Native mouse-input fix: clicks, dragging and wheel scrolling reach the transparent WebView host.
- Optional keyboard color sync, off by default, with manual lighting restoration.
- Native gaming HUD and existing hardware handlers retained. No AI/chat/model integrations.
- Expanded README screenshots covering every Jelli tab, lower sections, companion settings, summary, quick controls and native fallback/HUD previews.

## Download and run

Download **PredatorControl-standalone.exe**. Exit the existing instance through its tray, then run the new executable as Administrator. The Windows x64 .NET runtime and frontend assets are included; **Microsoft Edge WebView2 Evergreen Runtime** must be installed. No Node.js or separate frontend launch is required. `SHA256SUMS.txt` contains the executable's SHA-256 checksum.

Use `--legacy-ui` to open the retained native interface. Fan-curve and Game Sync profile editors continue to use native dialogs.

## Validation and limitations

The Release WebView fixture passed 39 checks, including native clicks/dragging/scrolling, reduced motion, lifecycle recovery and protocol behavior. ESLint, TypeScript/production build and all three frontend click-arbitration tests passed.

Screenshots use the real renderer with representative fixture preferences and unavailable sensor readings, not live hardware results. Compatibility varies by Acer model. Full physical hardware parity, mixed-DPI/docking, real-game overlay validation and the complete application's below-200 MB idle budget remain unverified; see the repository validation notes. The release does not claim those gates have passed.
