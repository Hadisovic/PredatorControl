# Predator Control v1.4.1

Release version `1.4.1` (`1.4.1.0`).

## Highlights & Fixes
- 🔒 **Windows & Menu Key Lock Restored**: Re-enabled physical keyboard lock for Predator Helios & Helios Neo models, synchronized across the main dashboard, tray menu, and Jelli companion UI.
- 🎮 **GPU MUX Switch Detection**: Restored dynamic GPU mode switching (Hybrid, Discrete, Auto) and corrected startup indicator status on Helios Neo systems.
- ⚡ **Predator Power Profiles & Jelli Status**: Improved thermal/power profile switching and isolated status badges from transient errors.
- 🧹 **IPC Cleanup & Optimization**: Streamlined background communication routines and cleaned up temporary build artifacts.

## Packages
- **`PredatorControl-standalone.exe`** — Self-contained single-file executable (no .NET installation required).
- **`PredatorControl-win-x64.exe`** — Lightweight single-file executable (requires .NET 10).
- **`PredatorControl-win-x64.zip`** — Portable archive distribution.
- **`checksums.txt`** — SHA-256 integrity checksums.
