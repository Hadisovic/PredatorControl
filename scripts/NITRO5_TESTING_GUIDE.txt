PREDATOR CONTROL v1.2.7 - ACER NITRO UNIVERSAL TESTING & FIELD GUIDE
================================================================================

1. WHAT'S NEW IN THIS BUILD:
--------------------------------------------------------------------------------
- 100% Generic Dynamic Detection (ZERO hardcoded model strings):
  * Works on ALL Acer Nitro models (Nitro 5, Nitro 16, Nitro 17, Nitro V)
  * Probes hardware capabilities dynamically via OEM service inspection,
    ACPI methods, and physical ITE RGB keyboard controller devices.

- Keyboard Backlight Auto-Detection:
  * Single-color / Monochrome backlit keyboards (e.g. Red Nitro 5):
    - Hides 4-Zone RGB dropdown, color pickers, and dynamic speed controls.
    - Shows dedicated "KEYBOARD BACKLIGHT" controls with 0-100% brightness
      and instant Turn Off support via WMI + Named Pipe EC dispatches.
  * 4-Zone RGB Nitro keyboards:
    - Retains full 4-Zone RGB color picker, effects, and profiles.

- Acer CoolBoost™ Support:
  * Repositioned directly below fan buttons, immediately above display refresh rate.
  * Zero dead space when Custom fan is collapsed.
  * Multi-channel dispatch:
    1) Named pipe ("nitrosense_hardware_service_")
    2) Acer Agent IPC (TCP port 46933)
    3) Direct ACPI WMI EC call (SetGamingFanBehavior with bit-24 / bit-8 flags)

- Single Refresh Rate Selector for 60Hz Panels:
  * If the notebook panel only supports 60Hz, it now renders a single [60 Hz]
    button instead of two redundant buttons.

- Jelli UI Fix:
  * Fixed NullReferenceException on non-MUX chassis (GTX 1650 / Nitro 5).

- Battery Health 80% Charge Threshold:
  * Dual-channel dispatch:
    1) BIOS ACPI WMI BatteryControl class (Predator & modern Nitro)
    2) Acer Care Center / ASMSvc registry keys (StopCharging = 80)
  * Keeps the toggle enabled and active on all Nitro systems.

- System Optimization Toggle Behavior:
  * Predator Laptops:
    - BIOS has native ACPI WMI classes (BatteryControl & AcerGamingFunction).
    - Safely disables all 6 Acer background services with zero lost features.
  * Nitro Laptops:
    - Hardware bridging services (ASMSvc, AcerDeviceEnablingService, AcerServiceSvc)
      are PROTECTED and PRESERVED so Battery Limit and CoolBoost work.
    - Only disables pure telemetry & bloatware (AcerCCAgent, AcerQA, AcerDI).
    - Auto-repairs and starts essential hardware services if they were disabled.

2. OUT-OF-THE-BOX OEM SERVICE SETUP (NO ACER CARE CENTER / NITROSENSE NEEDED):
--------------------------------------------------------------------------------
- You DO NOT need to download or install Acer Care Center or NitroSense!
- Simply double-click "Install-AcerNitroServices.bat" (or "Restore-AcerNitroServices.bat").
  It will automatically:
  * Request Administrator privileges (self-elevating UAC).
  * Install the required signed OEM driver packages from Windows DriverStore or
    the included "oem_drivers" folder.
  * Register and start ASMSvc (Battery 80% Limit) and AcerDeviceEnablingServiceV2 (Bridge).
  * Configure the 80% charge threshold registry keys.
  * Print a live status diagnostic confirmation showing each service RUNNING.

3. FILES IN THIS FOLDER:
--------------------------------------------------------------------------------
- PredatorControl-standalone.exe  -> Single-file self-contained (no .NET needed)
- PredatorControl-win-x64.exe     -> Framework-dependent (requires .NET 10 desktop)
- Install-AcerNitroServices.bat   -> 1-click self-elevating installer for Nitro services
- Restore-AcerNitroServices.bat   -> Identical alias for convenience
- oem_drivers/                    -> Bundled clean signed OEM driver packages
- checksums.txt                   -> SHA-256 integrity hashes
